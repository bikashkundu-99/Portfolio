Melody

GitHub URL

Tech Stack

Project Overview

Melody is a full-stack music streaming web application designed with a modern Spotify/YouTube Music-inspired experience. It includes authentication, music discovery, search, playback, liked songs, playlists, recently played music, lyrics, and an expandable music player.

The application uses a Java Spring Boot backend, HTML/CSS/JavaScript frontend, and Microsoft SQL Server for persistent data.

Key Features

  • User registration and login with a forgot-password and password-reset workflow.
  • JWT-based authentication and authorization.
  • Music search by title, artist, and album, alongside custom song recommendations.
  • Recently played songs, liked songs, and complete playlist creation & management.
  • Music playback controls with a bottom player and an immersive expanded player.
  • Lyrics display and timestamp-based synchronization (click a lyric line to seek playback directly to that timestamp).
  • Speech recognition for voice-based music search.
  • Dedicated "Your Library" interface driven by robust REST APIs and SQL Server persistence with Spring Data JPA.

Travelling Salesman Problem Route Optimizer

Intelligent Multi-Location Route Optimization

GitHub URL

Tech Stack

Python FastAPI Google Maps Platform Google Cloud Routes API Genetic Algorithms HTML CSS JavaScript

Project Overview

Travelling Salesman Problem Route Optimizer is an intelligent route optimization application that finds near-optimal travel routes across multiple locations using Genetic Algorithms. It integrates Google Maps APIs to calculate real-world travel distances and visualize optimized routes, helping users plan efficient multi-stop journeys.

The application combines evolutionary optimization techniques with real-world mapping data to solve the Travelling Salesman Problem (TSP), balancing computational efficiency with practical route planning.

Key Features

  • Genetic Algorithm Optimization: Implements population-based evolutionary search with selection, crossover, and mutation to discover near-optimal routes across multiple destinations.
  • Real-World Distance Calculation: Integrates Google Maps APIs to obtain road-network distances and travel information between locations.
  • Multi-Location Route Planning: Accepts multiple destinations and determines an optimized visiting sequence while minimizing the total route distance.
  • Interactive Route Visualization: Displays the optimized journey on a map, making the recommended travel sequence easy to understand.
  • Configurable Optimization Parameters: Supports tuning population size, number of generations, and mutation rate to experiment with solution quality and algorithm performance.
  • REST API Integration: Exposes route optimization functionality through FastAPI endpoints, enabling frontend integration and programmatic access.
  • Reproducible Optimization Runs: Supports a configurable random seed for consistent algorithm behavior during testing and performance comparison.

Sign Language Recognition

Real-Time ASL Alphabet Recognition Using Machine Learning

GitHub URL

Tech Stack

Python MediaPipe OpenCV Scikit-learn Intel oneAPI NumPy Random Forest Pickle

Project Overview

Sign Language Recognition is a real-time machine learning application that recognizes American Sign Language (ASL) alphabets from webcam input. It uses MediaPipe to extract hand landmarks and a Random Forest classifier optimized with Intel oneAPI to predict the corresponding alphabet, helping bridge communication gaps between sign language users and non-signers.

The model is trained on a manually collected dataset of hand gestures captured through a webcam, enabling real-time gesture classification without requiring image-based deep learning models.

Key Features

  • Real-Time Gesture Recognition: Detects hand gestures from live webcam video and predicts the corresponding ASL alphabet.
  • Hand Landmark Extraction: Uses MediaPipe to identify hand landmarks and transform gestures into structured machine learning features.
  • Random Forest Classification: Trains a supervised machine learning model to classify hand gestures into ASL alphabet categories.
  • Intel oneAPI Optimization: Uses Intel's optimized scikit-learn implementation to accelerate supported machine learning operations.
  • Custom Dataset Collection: Captures and labels hand gestures through a webcam to create a training dataset for model development.
  • Computer Vision Integration: Uses OpenCV for webcam access, video frame processing, and real-time prediction display.
  • Model Serialization: Uses Pickle to save and load the trained classifier for inference without retraining every time.
  • Supported Gestures: ASL alphabets A–Z, excluding J and Z in the current implementation.
